# 📘 یارسیماه — YARSEIMAH

**همراه هوشمند زبان** — برنامه‌ای کاملاً مرورگری برای یادگیری و کار با زبان انگلیسی، متکی بر کلید Gemini API خودتان. بدون نصب، بدون سرور؛ فقط فایل را باز کنید و شروع کنید.

<br>

## 🚀 شروع سریع

1. فایل `yarseimah.html` را از بخش [Releases](https://github.com/HEP-Devs/YARSEIMAH/releases/latest) دانلود کنید.
2. در [Google AI Studio](https://aistudio.google.com/) وارد شوید و از بخش **Get API key** یک کلید بسازید.
3. فایل را در مرورگر باز کنید، کلید را وارد کرده و «آزمایش اتصال» را بزنید. ✅

<br>

## 🧩 حالت‌های برنامه

| حالت | توضیح |
|---|---|
| 🌐 **مترجم متون** | ترجمهٔ فارسی ↔ انگلیسی با راهنمای تلفظ، دو سبک پخش **General** و **Street**، و ۱۰ مترادف و ۱۰ متضاد همراه مثال |
| 🎓 **یادگیری — پرسش** | پاسخ فقط به پرسش‌های مرتبط با دانش، تدریس و مهارت زبان انگلیسی؛ پرسش نامرتبط رد می‌شود |
| 👨‍🏫 **یادگیری — تدریس** | تبدیل متن یا حداکثر ۱۰ تصویر/PDF به درس خصوصی جامع: دستور زبان، collocation و expression، خطاهای رایج، تمرین و نکات IELTS — همراه خروجی PDF راست‌چین با فونت وزیرمتن |
| 📄 **مترجم اسناد** | پردازش جداگانهٔ چند تصویر، PDF یا فایل متنی؛ استخراج متن، تشخیص زبان و ترجمهٔ آمادهٔ کپی/دریافت |
| ✏️ **تصحیح متن** | اصلاح متن انگلیسی با لحن‌های فعلی، حرفه‌ای و رسمی، خیابانی، دوستانه یا دانشگاهی + گزینهٔ تغییر طول متن |
| 🖊️ **دستخط افتضاح من** | خواناترکردن فقط دست‌نوشته با حفظ کامل چیدمان ⚠️ نیازمند کلید Gemini دارای **Billing فعال** (محدودیت Google است، نه یارسیماه) |

<br>

## 🔐 امنیت

- 🔑 کلید API در دستگاه شما با **AES-GCM** رمز می‌شود و هرگز در لاگ، تاریخچه یا فایل HTML نوشته نمی‌شود.
- 🛡️ **کنترل یکپارچگی فایل**: هش کل فایل و همچنین کد، استایل، هویت، آیکون‌ها، حالت‌ها، عبارت‌ها، پیوند سازنده و اطلاعات دونیت جداگانه بررسی می‌شود؛ در صورت هرگونه دستکاری، رابط قفل و درخواست‌های API مسدود می‌شود.
- 💾 پشتیبان‌گیری اختیاری با گذرواژهٔ اجباری و رمزگذاری کامل فایل با AES-GCM.

<br>

## 🕵️ حریم خصوصی

- 🖥️ **کاملاً مرورگری** — بدون سرور واسط و بدون تلمتری؛ داده‌ها فقط روی دستگاه شما می‌مانند.
- 📡 تنها ارتباطات شبکه‌ای: ارسال مستقیم درخواست‌ها از مرورگر شما به **Gemini** و بررسی آخرین نسخه از مخزن رسمی GitHub.
- 📝 ثبت لاگ پیش‌فرض خاموش است و در صورت فعال‌سازی، کلید API و متن خصوصی عمداً از گزارش‌ها حذف می‌شود.
- ⚠️ برای استفادهٔ حساس یا مالی، استفاده از Backend امن و محدودسازی API Key در Google Cloud توصیه می‌شود.
